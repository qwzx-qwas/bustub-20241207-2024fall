## 3. 两项修正

### 3.1 排除校验和干扰

原极大长度测试修改字段后，仍保留旧 CRC。这样输入同时有两类损坏，抛异常不足以说明长度边界受到保护。

现在修改长度后重算并写入正确 CRC，保持正文非空。复用项目 CRC 函数仅用于生成输入，预期仍是独立的“结构非法必须拒绝、不得越界读取”；不是用两个 CRC 结果互相验证算法。

### 3.2 观察实际读取范围

仅要求抛异常，可能让已经越界的请求因 OS 错误被拒绝，从而掩盖解码器漏检查。

测试侧 `SliceCheckingStorage` 在现有读取边界检查路径、偏移和长度。违规时保留事实并拒绝访问，测试还会断言违规没有发生；合法请求继续真实读取文件。正常输入先经过同一观察器，避免观察器无条件拒绝造成假通过。测试只保护授权范围，不绑定合法请求的分块方式和次数。

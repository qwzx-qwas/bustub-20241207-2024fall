### 6.1 第二轮审查补充

建议本地事务提交成功同时代表恢复依赖 durable 与本地版本发布完成；接受/排队、字节 IO 完成和输入缓冲归还不得冒充该结果，具体表示见 F00 评审稿。旧 LogStore/StableStore 的同步 durable 保证须由兼容边界保留，不能为异步执行提前返回成功。

一事务中的对象、ControlKV、映射/引用和混合写策略共同决定原子范围；多个单独 API 调用恰好 group commit 不自动成为一事务。读需明确不存在、EOF、逻辑空洞、短 IO、损坏的区别。普通对象统一 IO 不强制元数据引导走依赖自身映射的路径。

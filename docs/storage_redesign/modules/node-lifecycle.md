### 6.1 第二轮审查补充

阶段按当前能力接入：S2 只打开基础对象；S5 恢复 B；S8 迁移 Raft Store 时 A 可继续现有文件工作库；S9 再接 A 的 FS 对象，仍保留快照加日志重建。S11 有可靠业务根后才改变直接恢复方式，不能把整个最终启动图都当成 S2 的前提。

S9 须替换当前清理工作目录/新建 generation 的生命周期效果，隔离新旧工作对象并在引用与在途 IO 结束后回收旧集。S8/S9 迁移的后端选择、旧格式识别/转换路径须另行冻结，不能由 Open 失败自动格式化。

节点控制器允许服务不等于存储已恢复，也不能凭控制器发出的停止命令销毁执行器；实际恢复/排空完成是能力发布的依据。

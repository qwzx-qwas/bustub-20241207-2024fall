## 6. 讨论后的方案与待冻结边界

以下为本轮收录的设计方向和约束；具体字段、数值、接口及当轮验收未确定前，不能把它们补成默认实现。

### 6.1 对象范围和 extent

一个物理 extent 是连续设备范围；普通对象可由多段非相邻 extent 构成，映射保证逻辑寻址。F12 尽量连续分配是性能策略，不是正确性前提；页按 K 分组进对象不保证物理相邻，也不减少查询需要的逻辑页数。

### 6.2 F36 释放和 S11 共享

F36 经 F26 释放的是对象内相应页范围，不能删除包含其他活页的对象。映射切换、分配事实与持久引用按本地事务更新；是否能立即归还物理空间取决于最小分配单位及 F14 的共享引用/读者/IO。A 的页内空闲字节摘要不重复充当本模块的设备映射。

S11 与 F28/F25 固定对象版本或映射根以支持一致快照，再由 COW 保护旧引用。对 canonical 正文不自动获得物理页共享。具体共享粒度、局部映射拆分、编码和原子发布仍需当轮冻结。

### 6.3 第二轮审查补充

页到对象的确定性公式必须包含 A/B 命名空间和业务工作库身份，当前重建可能重用页号。普通逻辑范围的分配代次、内容版本和对象生命周期分别保护寻址；并非把一个 Raft term 或 page_id 当成全部版本。可计算的 page→object 关系不重复持久化，但持久映射、分配和引用变化仍原子提交。

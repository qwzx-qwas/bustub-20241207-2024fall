## 11. 2026-10-02 S8 接续（当时授权，现已完成当轮范围）

### 本轮收录的具体职责

保留 current_term、voted_for、commit_index、格式/代次，以及现有合法性和单调性检查。小型正文直接保存在 B 控制值，复用 B 的 WAL/checkpoint；不另建同内容 Data 对象/WAL。校验 → B durable/发布 → 内存状态更新 → 返回成功。term/vote 的依赖响应不得提前；commit_index 必须有可恢复正文支持。

S8 同步 Update 等待真正提交，S7 Accepted 只表示任务归属；IO worker 不被 Store 等待占住，但现有 Raft 调用线程仍等待。结果不确定保留错误及恢复责任，沿既有 FailStop，不重试掩盖。

### 开源内化

[etcd/raft](https://raw.githubusercontent.com/etcd-io/raft/main/doc.go) 明确持久化和协议响应的依赖，即使采用异步消息也不能提前交付依赖响应；本项目落到同步 Store 成功边界，F35/S13 才接协议 event loop。[Raft Figure 2](https://raft.github.io/raft.pdf) 提供持久 term/vote/日志依据，本项目额外持久 commit_index 的既有契约保留。

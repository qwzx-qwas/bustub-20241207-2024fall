## 4. 开源参考与本项目落点

- [RocksDB checkpoint](https://rocksdb.org/blog/2015/11/10/use-checkpoints-for-efficient-snapshots.html)：同文件系统共享不可变 SST、另保存清单/必要日志以降低一致快照复制成本。内化为 F28 固定边界、F14 保留版本、F25 引用发布；BusTub 可变页/canonical 格式不能直接硬链接获得相同效果。核对：2026-09-21。

- [Btrfs reflink](https://btrfs.readthedocs.io/en/stable/Glossary.html#term-reflink)：为让多个视图共享数据，使用 extent 引用和修改时 COW。 内化为后续共享 extent 与 COW 视图；不直接复用 Btrfs 文件系统。 来源核对日期：2026-09-20。

项目代码的直接复制、依赖引入、版本或许可处理若在后续需要，应在讨论后的方案中明确；这里记录的是机制参考。

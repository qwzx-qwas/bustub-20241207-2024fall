## 6. 讨论后的方案与待冻结边界

以下为本轮收录的设计方向和约束；具体字段、数值、接口及当轮验收未确定前，不能把它们补成默认实现。

### 6.1 当前限制与职责

当前 CheckedReadPage/CheckedWritePage 缺页和脏页淘汰路径持 `bpm_latch_` 等待 DoDiskIO 的 future；FlushPage 也在全局锁内等待。DiskScheduler 仅有一个执行线程，文件后端共享 seek/read/write 锁。只加 IO 线程或单独解锁不能完整解决并发。

当前 DoDiskIO 未使用 future 的布尔结果，DiskScheduler 正常分支统一回调 true；接入时还须核对 DiskManager 的真实失败如何到达页调用者，不能仅增加异步状态而沿用无法表达后端错误的完成链。

F26 演进既有 BufferPool/PageGuard/页适配生命周期，F02 执行独立范围 IO，F32/F31 管缓存与工作内存；[F36](table-space-management.md) 判断记录/页能否释放。页内整理不放入 F26。

### 6.2 加载与等待

映射锁内只查找、固定帧、登记加载/淘汰状态和必要替换信息；锁外等待 IO 与页内容锁。先保留短全局映射锁，测得仍有竞争再讨论分区，不默认引入无锁结构。

```text
A 请求 page 7：预留帧及加载身份，登记 Loading，解锁后提交
B 请求 page 7：等待同一加载结果，不重复读取
C 请求 page 8：独立预留并提交，可与 page 7 并行
完成：核对页/帧代次 → 成功发布可用状态或错误 → 唤醒等待者
```

Loading 等仅表达概念状态，枚举与接口待冻结。映射存在不等于数据已有效；同一身份/版本才可合并等待。锁内保存稳定帧引用并 pin，不能解锁后继续使用可能失效的映射表迭代器。帧在 IO/读者引用期间不可复用；每次重用的代次用于拒绝旧回调，不能只核对 frame_id。

### 6.3 脏页写回和淘汰

- 写回必须捕获受页内容保护的稳定版本。候选第一步为 IO 期间保护该页内容；后续可用受预算约束的稳定副本缩短页锁时间。具体选择须冻结，不默认建立 FS 干净页缓存。
- 比较送出版本与当前修改版本：v5 写回完成后若内存已是 v6，不能清除 v6 的脏状态；同页写回仍要有顺序/完成边界，不能让旧写覆盖新写。版本捕获、脏标记及 PageGuard 生命周期须一起适配。
- 淘汰先保护旧帧并登记状态，必要写回达到约定完成边界后再解除旧映射、装入新页；其他页可以推进。同页访问应等待/重试正确状态，不另读出旧设备副本。
- 失败保留仍必要的脏内容，通知全部相关等待者并解除正确的预留；不得返回半页或把 false/异常当成功。完成和取消也须归并资源，不能释放后接受迟到回调。
- 页可从缓存释放、写入完成和 durable 的区别归 F00。只有后端可靠接管对应版本及其所有权后才能释放；业务 checkpoint 另等待所需 durable/发布边界。

### 6.4 上下游与兼容

F02 要有多个有界在途 IO；文件模拟后端若仍共享可变文件位置，须由 F01/F02 定位 IO/后端同步方案解决。保持已有同步 PageGuard 正式接口的同时允许独立调用并发；单调用持续读一页再等一页不会自动生成并发，有限预读另按 F32 讨论。没有可用帧时沿用明确的资源不足契约，不把任意生产失败隐藏为无限等待。

A/B 是独立运行实例但可能复用 BufferPool、PageGuard 等代码。变更共享实现时回归 F08 私有页、WAL 先行、错误传播和 B 恢复，不把 A 的 Raft index、表页格式或 F36 回收规则强加给 B；也不能简单让通用脏页刷写绕过 B 的提交约束。

### 6.5 S9 顺序和释放

S9.1 先完成上述页生命周期与 IO 接入；S9.2 的 F36 使用其保护做页内整理与复用；S9.3 在引用、页链、读者/IO、旧页号失效和恢复条件成立后，执行 F36 → F26 → F22 → F12 释放。释放对象内一个页范围不等于删除包含其他活页的整个对象。条件缺失时暂缓整页释放，不延后基本正确性。

### 6.6 第二轮审查补充

对象分组中的数据库身份须包含工作库重建的独立身份。当前 BusTubRaftStateMachine::InitializeEmpty 会清理工作目录，InstallSnapshotFile 构建候选工作库后切换；新 FS 对象不会因删目录自动消失。S9 须定义创建新身份、切换和旧工作集回收，不允许只用重新开始的 page_id 寻址旧对象。

零初始化新页是页层明确的动作，设备短读或映射损坏不得伪装为新页。B 的私有页/WAL 适配在 S4/S5 已实现；本模块并发改动须保留这些既有约束。F26 的工作页可写出不代表已有 F28 一致恢复根。

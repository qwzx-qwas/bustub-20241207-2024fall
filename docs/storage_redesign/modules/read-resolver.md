#### S10 复审补充：读取错误与合计预算

Journal/Data 读取真实 IO 失败均进入现有节点故障通道，不能因丢弃结果而吞掉错误；完成后通知仍在 F02 终态发布之后。F21/F07 使用 F02 的正式合计预算检查区分永久超限和临时占用，计算完整 Journal 批次、Data 范围及对齐缓冲。不会把容量不足伪装为设备错误或无限重试，不新增测试 getter。测试和证据共用 [S10 复审](../s10_execution_20261005.md#十再次复审读取错误和混合来源预算)，不复制一套底层计数测试。

## 2. 逐项：目标 → 输入 → 执行 → Oracle → 失败含义

共同路径：正式 F13 → 正式 B/F12 → Journal/MetadataBackend → F04/F02/F01 → 默认 Direct 普通文件。使用原 S5 的 8 MiB 临时设备镜像（Data 2 MiB），显式预算，真实查询设备对齐；非零正文由固定模式产生。测试侧 `ReadBody` 将正式 Resolve 的 Data/Hole 返回结果接入现有 RegionManager IO，预期正文取自输入向量，不从映射算出 expected。它不是尚未实现的 F21 对象读服务或节点层。

### 2.1 IdentityFormatAndTombstone

- **目标：** 同对象号在不同持久空间互不混淆，删除不容许身份复用，Open 不创建格式。
- **输入：** 无 F13 格式但 B 有 51 字节其他数据；两个空间的对象 7，长度 321/654、变长/固定两种模式；旧 snapshot。
- **执行：** Open 拒绝 → Create → 两次 CreateSpace/CreateObject → Remove → 重复创建/格式化被拒 → checkpoint → 关闭重开，再分配空间。
- **Oracle：** 空间不同；仅第一对象不存在且不能同号重建；旧 snapshot 保持 321，第二对象仍为 654；其他 B 值逐字节不变；重开后的新空间号大于已发布号。依据是输入身份和 API 约定，与树/编码无关。
- **失败含义：** 格式生命周期、空间隔离、墓碑或持久身份错误。此处旧 snapshot 只证明元数据视图，不代表已完成 F14 数据保留。

### 2.2 ScatterLookupReplacementAndOldView

- **目标：** 逻辑连续数据即使物理分散，任意中间位置也正确；局部替换不破坏两端或旧版本。
- **输入：** 通过正式隔离接口只留下物理起点 2u/5u/9u 的三段，逻辑起点为 O=7u+137（与物理位置不同且未按 IO 对齐），写 3u 字节。覆盖非零段起点、第一/第二段内部、第三段尾部、跨三段分页；另测前导空洞到正文。再覆盖 `[O+u/2,O+1.5u)`，从新段内部和右侧保留片内部读取。u 为显式配置的实际分配粒度。
- **执行：** Reserve/Lease → 初始化完整对齐范围 → 真实写与 Flush → Replace；同一 snapshot Resolve 分页并真实读取；覆盖后分别读新旧 snapshot，使用旧 base 修改必须冲突。
- **Oracle：** 完整结果等于输入切片；替换后等于外部向量 patch；旧视图仍等于原正文；退出两片各 u/2，逻辑起点分别 O+u/2、O+u，分配身份不同；被拒请求后正文不变。未读内部映射表建立 expected。
- **失败含义：** 前驱遗漏、跨页/跨范围错误、切片物理偏移错误、错误修改旧版本，或陈旧修改被接纳。

### 2.3 TruncateExtendAndDurableRetirement

- **目标：** EOF 以后退出的数据不因再次扩展暴露，回收依据持久存在且不代表已安全释放。
- **输入：** 3u 非零正文缩到 u+13，再扩到 4u；固定对象 2u，仅后半写 u；请求跨 EOF 和在 EOF 以后。
- **执行：** 真实 Put → Resize → Resolve/IO → checkpoint → 重开；重开后从 u−11 读到对象末尾，覆盖保留数据与清零边界，避免重复从 0 完整读取；按实际容量申请剩余 Data。
- **Oracle：** 输出为输入前 u+13 字节加零，跨 EOF 截断、EOF 后空；固定对象长度保持 2u 且拒绝缩短；重开后相同；退出范围恰为 `[u+13,3u)`；原三个单位与固定对象一单位仍占用，申请所有其他容量后 NoSpace。
- **失败含义：** 旧尾部复活、EOF/固定模式失效、持久清理信息遗失或提前回收。读取通过同一 Resolve，但 expected 零区独立构造，不用生产编码作 oracle。

### 2.4 PredecessorAcrossTreePages

- **目标：** inclusive floor 在多个叶子页、删除空隙中正确，键和值对应。
- **输入：** 先插入 240 个不同键/19 字节值，再填入 120 个间隙键；一次删除原键中每三条的一条（从第 1 项开始）；查询覆盖相等、间隙、全局最前和末尾。
- **执行：** 原 B.Commit 创建/删除记录；新 B.GetFloor → 共享树查询 → B 记录页取值。使用实际持久化 B，不手造树页面或修改页容量。
- **Oracle：** `std::map` 仅保存输入数据，用 upper_bound 后退得到数学上的最大不大于项，与生产 B+Tree 完全独立；比对完整键和值，最前查询无结果。
- **失败含义：** 前驱定义、树下降/左侧回退或记录定位错误。已有树插入/删除课程测试没有这个查询契约。
- **覆盖审查修正：** 首版顺序插入加均匀删除使叶子重分配，删除左侧回退的变异竟能通过。先分析实际删除逻辑，非顺序插入仍未触发；最终使用真实填隙插入后单轮删除，让不触发重分配的首键删除产生查询空隙；不读取内部页或硬编码某个分隔键。中间多轮删除/恢复耗尽 8 MiB 夹具的 Journal，已删去多余循环，生产预算未改；最终一轮输入同时满足正常通过、缺失回退时指定断言失败。首版漏检或夹具资源拒绝不计入最终通过。

### 2.5 BudgetRefusalPreservesStateAndReservation

- **目标：** F13 拒绝应在完整事务之前，不能丢失旧状态或绕过业务前置条件。
- **输入：** 两个独立映射，待处理记录预算仅 1，缩为零需要退出两条；另一个已写好的预留及一个陈旧 snapshot。
- **执行：** 超预算 Resize 拒绝；对象先由新事务扩展，旧 base Replace 被 B 拒绝；调用方重新读取后使用同一个预留提交。
- **Oracle：** 超限后长度仍为 2u 且没有退出记录；旧 base 必须 Conflict；预留未被拒绝消耗，新 base 成功且正文等于独立输入。没有通过内部 reservation 状态 getter 验证。
- **失败含义：** 部分发布、预算忽略、隐式刷新前置条件、失败消耗申请。复用 F12 的预留机制，不重复其位图/层次搜索矩阵。

### 2.6 FailedPublicationRecoversWholeChange

- **目标：** 数据正文已 durable 不等于对象版本可见；映射、退出依据和分配事实作为一笔提交恢复。
- **输入：** 旧/新各 u 字节且内容不同，映射位于非零逻辑起点 2u+113；新正文已 durable；实际 Journal 的 fdatasync 被测试链接包装暂停，放行时返回一次 EIO。
- **执行：** 异步 Replace，暂停确认后读现有对象，再注入失败；关闭并重开 B/F12/F13。
- **Oracle：** 暂停时只能读旧正文且无退出记录；结果不得 Durable 且有错误，随后新读被 B 拒绝。恢复若为新正文，版本必须 3、有一条退出记录、两单位都占用；若为旧正文，版本必须 2、没有退出记录、只一单位占用。通过独立输入和可申请容量检查跨事实关系。
- **失败含义：** 提前发布、错误后继续服务或半笔恢复。失败 Flush 后允许完整新/旧结果，不能用测试猜介质到底持久化了哪一种；EIO 不是物理掉电模拟。未要求“报错必然恢复旧状态”。

## 4. 接口和职责污染审查

A/B 共用树只增加正式查询方法，未改原读写含义、键值布局或构造行为。F13 在 B 通用值中编码自己格式，不修改 B 磁盘页/WAL 格式；F12 位图和分配格式保持原样。只对进入磁盘编码/预算的必要值作检查，不重复校验整个对象图、不隐藏底层错误。

F13 返回 Data/Hole 计划；它不读取正文、判断 SQL/Raft 有效记录、调度后台 GC 或承诺 pin。新接口层次各有正式消费者/后续组装职责，没有独立服务或无生产价值的转发层。

## 5. 重复与跨阶段接管

- Scatter 测定位/切片/旧视图；Truncate 测逻辑 EOF/再次扩展/持久退出，风险不同，保留。
- Predecessor 直接保护新增 B 查询；Scatter 检查 F13 使用它并转成正确物理切片。范围查询端到端涉及多个组件，但目前不能代替跨叶子空隙这一输入条件；不新写另一套树插入/删除测试。
- Budget 的旧 base 检查专门保护 F13 不自动刷新 base；F12 旧测试保护 allocator 自己。直接复用原套件，没有重新复制其测试矩阵。
- Failure 保护具体对象描述/映射/退出/F12 的组合；原 F12 检查任意附带键值原子性。后者不能保证 F13 确实把所有对象变更加入了同一事务。
- 原 F34、S5、A 测试只作为本轮受影响路径回归，不计为本轮新增测试或第三方特性验证。
- 风险归属 `F13/identity、range-read、truncate-retire、floor-query、bounded-publication、atomic-recovery`。后续 F14/S6 owner/F21/F26/F25 的真实链路接入时，复用这些输入和独立 byte/capacity oracle，替换当前测试侧读适配，避免每层复制同义场景。
- 长期常驻仍是共同生产 C/P E2E；本轮小测试仅压缩归档。尚无完整对象服务，所以不能声称这些风险已被 C/P 接管。

## 6. 故意改坏与检出标准

每个变异在仓库外生成、编译链接真实生产库。必须退出 1 且 XML 含指定断言；编译失败、崩溃和超时一律不算检出。

| 变异 | 预期保护 |
| --- | --- |
| Resolve 无论查询何处都只找逻辑起点 0 的前驱 | Scatter 的非零段内部正文不同 |
| 物理起点加查询位置但忘减映射逻辑起点 | Scatter 的非零范围正文不同 |
| 切片不增加物理起点 | Scatter 的部分覆盖两侧正文不同 |
| Resize 不裁掉旧映射 | Truncate 的扩展零区出现旧数据 |
| 不持久化退出记录 | Truncate 退出记录数不符 |
| Replace 偷换为 B 最新 snapshot | Budget 的陈旧提交被错误接纳 |
| 忽略待处理条数预算 | Budget 应拒绝而提交 |
| 允许删除对象同号重建 | Identity 应拒绝而成功 |
| 树下降不记左侧子树 | Predecessor 的删除后空隙查询错误 |

精确变异内容、编译/运行命令、失败 XML 与最终结果见压缩证据。没有给每个字段都造一个变异；未声称穷尽并发调度和故障组合。

## 7. 稳定性

每个场景单独临时镜像，使用固定字节和固定填隙/删除顺序，无 seed 漂移、sleep 或执行顺序依赖。原 F12 的链接级 gate 为进程内全局，单个 GTest 进程串行运行；不可在同进程另开并行测试而不隔离 gate。异步场景等待明确进入事件，RAII 放行，先放行再等待 future；看门狗仅防死锁，耗时不作为正确性 oracle。

设备必须支持当前 F01 Direct 文件路径与可查询对齐；无法支持时报明确环境失败，不静默切 Buffered。夹具容量/预算是显式测试设置，并非生产默认。ASan/UBSan 不等于 TSan；有界并发和重启验证不代表物理掉电、裸设备或性能结论。

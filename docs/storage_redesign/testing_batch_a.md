## 实施细节

1. 驱动最多 8 个工作线程、8 个排队请求；运行器每客户端等待当前结果后再继续。
2. Python 输入计划保存业务输入、身份和 SQL；驱动分别保存调用与返回事件。两份产物按关联号连接，进程异常时没有返回的调用仍可识别。
3. P2 测量窗口使用驱动时钟。超过窗口才获得执行机会的请求标为未发出，不冒充实际尝试；窗口内调用的尾部结果继续保留。
4. 正式写响应没有 affected-row 数量；不能伪造。C1 和健康 P2 通过最终完整业务结果验证更新确实生效。
5. `raft_process_harness.sh` 原有节点启动参数将业务等待固定为 3 秒，而且生产 CLI 拒绝重复参数。仅在测试 harness 增加可选 `RAFT_CLIENT_TIMEOUT_MS`，默认保持 3 秒，A 显式传 5 秒；不改变生产默认值或旧场景。
6. Linux `/proc` 采样记录三个节点、Python、驱动的 CPU/RSS/IO，以及主机内存、设备统计和实验目录占用。预算为观测停止条件，不宣称 cgroup 硬限制。设备统计可能包含其他进程及采集 IO，不能当作精确写放大。
7. C1/P2 失败不自动重跑；P2 3 次重复是预定实验。每次新目录，完整保存错误与退出状态；不删除旧数据或清空系统缓存。
8. 资格运行和基线运行使用显式标记；本批次可运行 C1 或一个 P2 参数点，也可顺序执行整个 P2 矩阵。参数改变写入配置及哈希，不能混进同条件比较。
9. 单参数点的外部总预算通过 `--max-seconds` 明确记录，初始为 600 秒（含准备和核对，清理另有有限宽限）。P2 资格运行必须检查是否足够；不足时报告并商讨共同配置，不能减少业务工作量。资格模式只运行一个参数点且不超过 600 秒；整轮资格步骤仍需控制在 30 分钟内。

### 发现与处置

1. **阻塞，未修复：当前建表请求会被生产路径拒绝。** [adapter.py](../../test/storage_acceptance/adapter.py) 声明 `VARCHAR(1024)`，而 [Column::TypeSize](../../src/include/catalog/column.h) 返回 `uint8_t`，使长度 1024 变为 0。[PrepareCreateTable](../../src/distributed/sql_command_preparer.cpp) 将这个值写入复制命令，[CommandBody](../../src/distributed/command_codec.cpp) 拒绝长度为 0 的列。因此 C1/P2 均无法进入数据装载，更不能产出有效性能基线。这是源代码路径推导，没有用运行结果代替审查。需另行明确是独立修复生产列长度缺陷，还是在建立两版基线前共同调整数据契约；本轮不修改生产代码、不悄悄缩短正文，也不由适配器拆列来伪造支持。
2. **覆盖缺口，未修复：C1 未覆盖正文长度变化。** [c1_updates](../../test/storage_acceptance/content.py) 用旧正文长度生成新正文；初始数据变长并不等于更新发生长度变化。实施提案的 ReplacePayload 明确包含长度变化，但目前只能核对同长度替换。应在共同长度规格确定后，明确固定的增长/缩短序列并补入 C1；不能声称已覆盖变长更新的搬迁或截断风险。
3. **已修改，未执行验证：移除完整 SQL 拼写断言。** 原工具自检逐字要求两条 UPDATE 的空格、拼写和赋值顺序，这些不是跨版本业务契约。现删除这两处断言及失去用途的导入，保留独立业务预期、重复行/丢更新拒绝，以及正文引号和控制字符保真检查。完整 SQL 的真实执行仍由 C1 验证；正文转义自检不冒充端到端执行证明。

## 开源参考及本地落点

- [etcd interfaces](https://github.com/etcd-io/etcd/blob/main/tests/framework/interfaces/interface.go)：测试能力与场景分离，内化为 content/adapter/runtime 分层。
- [YCSB CoreWorkload](https://github.com/brianfrankcooper/YCSB/blob/master/core/src/main/java/site/ycsb/workloads/CoreWorkload.java)：数据与访问分布分开，内化为确定性合成数据和 P2 每客户端独立访问流；不照搬客户端先读后写。

- [etcd 未知结果模型](https://github.com/etcd-io/etcd/blob/main/tests/robustness/model/non_deterministic.go)：未知不等于未执行，内化为完整尝试历史和健康场景停止该客户端；并发搜索属于 B 批次。
- 本项目现有 `raft_process_harness.sh`：复用生产进程启动、退出检查和清理；现有 CLI 的正式解码接口供新驱动复用，不使用旧基线脚本的私有协议实现。

# 既有 Raft 与恢复回归测试

本目录归档新旧存储对比套件建立前的相关测试，避免与 [storage_acceptance](../storage_acceptance/README.md) 混淆。

- `distributed/`：SQL 复制命令、会话、协议、状态机及节点集成测试。
- `raft/`：Raft 状态转换、复制、传输、日志及稳定状态测试。
- `recovery/`：版本化格式、持久化与故障模型、快照和重开测试；保留原禁用课程恢复文件的状态。
- `e2e/`：M0–M8 既有进程时间线与组件 gate。
- `storage_baseline.py`：旧的探索性测量脚本，仅作历史阅读材料；不是新的正式运行入口，其原始结果没有获得基线认可。

28 个有效 C++ 测试目标名称保持不变，CMake、CI 和 gate 的源码发现路径已迁移，仍执行原有回归职责。共享的 harness/代理已经移入 [support](../support/README.md)，这里只有场景，不复制工具。

原始测量产物仍在 `docs/performance/`，不移动、不改写或追认。旧测试绑定的文件布局和故障点，在未来后端替换时另行审查，不作为新旧共同业务契约。协议和持久化格式的兼容性测试仍保护当前正式承诺。
